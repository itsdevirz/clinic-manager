# راهنمای ساخت خروجی ویندوز (Tauri EXE) در لینوکس با بکند متصل

این راهنما نحوه ساخت فایل اجرایی ویندوز (`ClinicManagement.exe` و فایل نصبی NSIS) را مستقیماً از داخل سیستم‌عامل **لینوکس** (Ubuntu, Debian, Fedora, Arch, Manjaro و ...) توضیح می‌دهد، به‌طوری‌که **بکند اکسپرس و اتصال به دیتابیس MySQL** به صورت خودکار و کامل متصل باشند.

---

### معماری اتصال بکند و فرانت‌اند در فایل اجرایی
1. **فرانت‌اند React:** با Vite کامپایل شده و در داخل Webview نیتیو ویندوز اجرا می‌شود.
2. **بکند Node.js/Express:** تمامی منطق اتصال به MySQL (`/api/db/test`, `/api/db/sync`, `/api/db/load` و ...) توسط `esbuild` به یک فایل یکپارچه `dist-server/server.cjs` باندل می‌شود.
3. **هماهنگی هوشمند در Tauri:**
   - کدهای Rust در `src-tauri/src/lib.rs` به هنگام باز شدن برنامه، پروسه سرور بکند را به صورت خودکار در پس‌زمینه اجرا می‌کنند.
   - به هنگام بستن پنجره برنامه، پروسه بکند نیز خاتمه می‌یابد.
   - کلاینت React در حالت دسکتاپ تمام درخواست‌های API را مستقیماً به آدرس پورت محلی `http://127.0.0.1:3000` هدایت می‌کند و مشکل عدم اتصال یا عدم بارگذاری حل شده است.

---

## روش سریع و خودکار (۱ دستور در لینوکس)

کافیست در ترمینال لینوکس وارد پوشه پروژه شوید و دستور زیر را اجرا کنید:

```bash
./build-linux.sh
```
یا
```bash
bash desktop-builder/build-linux.sh
```

این اسکریپت تمام مراحل زیر را به صورت خودکار و گام‌به‌گام انجام می‌دهد:
1. بررسی نصب بودن Node.js و Rust.
2. اضافه کردن تارگت ویندوز (`x86_64-pc-windows-gnu`) به `rustup`.
3. بررسی وجود لینکر `x86_64-w64-mingw32-gcc` و ابزار NSIS.
4. کامپایل فرانت‌اند و بیلد کامل بکند (`npm run build:all`).
5. کامپایل باینری ویندوزی توسط Tauri.
6. انتقال فایل‌های نهایی به پوشه `desktop-output/windows/`.

## پیش‌نیازهای یک‌بار نصب در توزیع‌های مختلف لینوکس

اگر برای اولین بار در لینوکس خروجی ویندوز می‌گیرید، بسته‌های کراس‌کامپایل را با دستور متناسب با توزیع خود نصب کنید:

### ۱. اوبونتو / دبیان / مینت (Ubuntu / Debian / Linux Mint):
```bash
sudo apt-get update
sudo apt-get install -y gcc-mingw-w64-x86-64 nsis nodejs npm
# نصب تارگت ویندوز در راست
rustup target add x86_64-pc-windows-gnu
```

### ۲. آرچ لینوکس / مانجارو (Arch Linux / Manjaro):
```bash
sudo pacman -S mingw-w64-gcc nsis nodejs npm
rustup target add x86_64-pc-windows-gnu
```

### ۳. فدورا (Fedora / RHEL):
```bash
sudo dnf install -y mingw64-gcc mingw32-nsis nodejs npm
rustup target add x86_64-pc-windows-gnu
```

## دستورات دستی در ترمینال لینوکس (بدون اسکریپت)

اگر مایلید مراحل را دستی گام‌به‌گام اجرا کنید:

```bash
# ۱. نصب پکیج‌ها
npm install --legacy-peer-deps

# ۲. کامپایل فرانت‌اند و بکند سرور
npm run build:all

# ۳. بیلد خروجی EXE ویندوز با Tauri
npm run tauri:build:win
```

## محل فایل‌های ساخته‌شده پس از اتمام بیلد

فایل‌های ساخته‌شده در مسیر زیر قرار می‌گیرند:

```
desktop-output/windows/
├── ClinicManagement_1.0.0_x64-setup.exe   <-- فایل نصاب رسمی ویندوز (Setup Installer)
└── ClinicManagement-Portable/             <-- نسخه بدون نیاز به نصب (Portable)
    ├── ClinicManagement.exe               <-- فایل اجرایی اصلی برنامه
    ├── dist-server/
    │   └── server.cjs                     <-- بکند متصل به پایگاه داده
    ├── mysql-config.json                  <-- تنظیمات پورت و دیتابیس
    └── start-clinic.bat                   <-- شورت‌کات اجرای یک‌کلیکه
```

## روش جایگزین: ساخت خودکار ابری با GitHub Actions (بدون نیاز به ابزارهای محلی)

اگر روی سیستم لینوکس خود نمی‌خواهید بسته‌های کامپایلر سنگین نصب کنید:
1. پروژه را در ریپازیتوری گیت‌هاب پوش کنید.
2. وارد تب **Actions** در گیت‌هاب شوید.
3. ورک‌فلو **"ساخت خودکار فایل خروجی ویندوز (Tauri Desktop EXE)"** را انتخاب کرده و روی **Run workflow** کلیک کنید.
4. سرورهای مایکروسافت به صورت ابری فایل `.exe` کامل و بکند را ساخته و لینک دانلود آن را در بخش Artifacts به شما تحویل می‌دهند.
