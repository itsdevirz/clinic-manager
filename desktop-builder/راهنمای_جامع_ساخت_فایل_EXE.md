# راهنمای کامل ساخت خروجی نرم‌افزار دسکتاپ ویندوز (فایل EXE) با Tauri

این پوشه و پیکربندی اختصاصی برای تبدیل سامانه مدیریت مطب و کلینیک به یک نرم‌افزار فوق‌العاده سریع، سبک و امن دسکتاپ ویندوز با فریم‌ورک مدرن **Tauri v2** آماده شده است.

---

### چرا Tauri به جای Electron؟
* **حجم نهایی بسیار کم:** فایل خروجی فقط بین **۱۰ تا ۱۵ مگابایت** خواهد بود (در مقایسه با بیش از ۱۵۰ مگابایت Electron).
* **مصرف رم و منابع بسیار ناچیز:** از موتور پیش‌فرض ویندوز (Microsoft Edge WebView2) استفاده می‌کند و پردازنده و رم سیستم مطب را اشغال نمی‌کند.
* **سرعت بالا و اجرای بدون لگ:** مناسب سیستم‌ها و لپ‌تاپ‌های منشی، پذیرش و پزشک.
* **امنیت بالا:** بدون دسترسی‌های ناخواسته اینترنتی و با امکان کارکرد کاملاً آفلاین.

---

## روش سریع و ۱-کلیکه برای ساخت EXE

1. پروژه را روی کامپیوتر ویندوزی خود دانلود یا کپی کنید.
2. وارد پوشه `desktop-builder` شوید.
3. روی فایل **`build-exe.bat`** دابل‌کلیک کنید!
4. اسکریپت خودکار بسته‌ها را چک کرده، فرانت‌اند را بیلد می‌کند و فایل خروجی را می‌سازد.
5. پس از پایان، پنجره پوشه خروجی به صورت خودکار برای شما باز خواهد شد.

---

## پیش‌نیازهای اولیه سیستم برای بیلد گرفتن (فقط یک‌بار)

برای اینکه ویندوز بتواند کدهای Rust را به فایل باینری نیتیو `.exe` تبدیل کند، سیستم شما به دو ابزار استاندارد زیر نیاز دارد:

1. **نصب Node.js (نسخه ۱۸ یا بالاتر):**
   - دانلود از: [nodejs.org](https://nodejs.org)

2. **نصب Rust (کامپایلر کارگو):**
   - دانلود فایل نصاب `rustup-init.exe` از سایت رسمی: [rustup.rs](https://rustup.rs)
   - هنگام نصب، گزینه پیش‌فرض (شماره ۱) را بزنید تا C++ Build Tools را هم پیکربندی کند.
   - *یا دستور خودکار زیر را در PowerShell اجرا کنید:*
     ```powershell
     winget install Rustlang.Rustup
     ```

3. **ابزار Microsoft C++ Build Tools:**
   - اگر از قبل Visual Studio روی سیستمتان باشد به صورت خودکار وجود دارد.
   - اگر نبود از لینک [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) تیک گزینه *Desktop development with C++* را بزنید.

## روش دستی از طریق خط فرمان (Terminal / CMD)

اگر مایلید مستقیماً با دستورات ترمینال فایل را بسازید:

```bash
# ۱. نصب پکیج‌های پروژه
npm install

# ۲. اجرای دستور ساخت خروجی دسکتاپ
npm run tauri:build
```

---

## محل دقیق فایل‌های خروجی EXE ساخته‌شده

پس از اتمام بیلد، فایل‌ها در دو حالت در سیستم شما آماده هستند:

1. **فایل نصبی ویزاردی خودکار (Setup Installer):**
   ```text
   src-tauri/target/release/bundle/nsis/ClinicManagement_1.0.0_x64-setup.exe
   ```
   این فایل را می‌توانید روی هر ویندوز ۱۰ یا ۱۱ دیگر ببرید و با چند کلیک مثل نرم‌افزارهای استاندارد نصب کنید (با آیکون در منوی استارت و دسکتاپ).

2. **فایل پرتابل بدون نیاز به نصب (Standalone Portable):**
   ```text
   src-tauri/target/release/ClinicManagement.exe
   ```
   فقط کافیست روی آن کلیک کنید تا سامانه اجرا شود.

## اجرای زنده در حالت توسعه (Dev Mode)

اگر می‌خواهید تغییرات را هم‌زمان در پنجره دسکتاپ مشاهده و تست کنید:
* دابل کلیک روی `run-dev-mode.bat`
* یا اجرای دستور:
  ```bash
  npm run tauri:dev
  ```

---

## تنظیمات فایل `tauri.conf.json`

تمامی تنظیمات نرم‌افزار دسکتاپ اعم از ابعاد پنجره (عرض و ارتفاع)، عنوان پنجره، دسترسی‌ها و آیکون‌ها در مسیر:
`src-tauri/tauri.conf.json`
قرار دارد و در صورت تمایل به تغییر سایز یا نام برنامه به راحتی قابل شخصی‌سازی است.

## 🛠️ راهنمای رفع خطای `linker link.exe not found`

اگر با این خطا مواجه شدید:
```text
error: linker `link.exe` not found
note: the msvc targets depend on the msvc linker but `link.exe` was not found
note: please ensure that Visual Studio 2017 or later, or Build Tools for Visual Studio were installed with the Visual C++ option
```

### علت:
زبان Rust روی ویندوز برای تبدیل کد به فایل اجرایی `.exe` به ابزار کامپایلر مایکروسافت به نام **`link.exe`** نیاز دارد. دقت کنید که نرم‌افزار VS Code صرفاً یک ادیتور متنی است و کامپایلر ندارد.

### راه‌حل‌های حل فوری:

#### روش ۱ (ساده‌ترین روش - فقط اجرای اسکریپت):
در همین پوشه `desktop-builder`، روی فایل **`fix-linker-error.bat`** دابل‌کلیک کنید و گزینه شماره ۱ را بزنید تا C++ Build Tools را به صورت خودکار نصب کند.

#### روش ۲ (اجرای یک خط دستور در ترمینال یا PowerShell به عنوان Administrator):
```powershell
winget install Microsoft.VisualStudio.2022.BuildTools --override "--passive --wait --add Microsoft.VisualStudio.Workload.VCTools"
```

#### روش ۳ (دانلود دستی نصاب رسمی مایکروسافت):
1. وارد لینک رسمی مایکروسافت شوید:
   [دانلود Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)
2. فایل `vs_BuildTools.exe` را اجرا کنید.
3. در صفحه انتخاب بسته‌ها، حتماً تیک گزینه **Desktop development with C++** (توسعه دسکتاپ با ++C) را علامت بزنید و روی Install کلیک کنید.
4. پس از اتمام نصب، پنجره ترمینال را ببندید و مجدداً باز کنید؛ سپس دستور `npm run tauri:build` یا فایل `build-exe.bat` را اجرا نمایید.
